# 이전 소켓 서버 문서

이 폴더는 이전 방·채팅·틱·GameWorld 설계와 구현 기록을 보존합니다.
문서에 적힌 "현재 구현"과 완료 표시는 당시 브랜치 기준이며, 현재 session 기반 서버의 기능을 의미하지 않습니다.
본문의 옛 코드 상대 경로도 당시 저장소 기준입니다.

현재 구현은 [소켓 서버 README](../../../socket-server/README.md),
통신 규약은 [실시간 계약](../../../contracts/realtime/README.md)을 참고하세요.
이전 코드가 필요하면 기존 Git 이력 또는 이전 기록의 원본 저장소 백업을 확인합니다.
