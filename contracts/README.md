# 프로젝트 간 통신 계약

- [realtime](realtime/README.md): `.proto`와 메시지·오류 번호가 원본입니다. 생성된 C++/C# 상수를 함께 검증합니다.
- [http](http/README.md): API 구현에서 생성한 OpenAPI 스냅샷입니다. 미구현 설계는 포함하지 않습니다.

클라이언트와 서버 구현 코드는 각 프로젝트가 소유합니다. 이 디렉터리에는 전송 형식과 호환 규칙을 둡니다.
계약 변경 PR에는 송신·수신 양쪽 구현, 생성 결과, 통합 테스트 결과를 포함합니다.
기존 배포 클라이언트의 호환성을 확인하고, Protobuf 필드 번호를 재사용하지 않습니다.
